Modules sur mesure

Une fonction qui n'existe dans aucun bot ? Elle sera codée exprès pour ton serveur, puis ajoutée à Cyber en saisissant un simple identifiant, comme une cassette qu'on insère.

  1. 1

    Tu décris ton idée

    Sur le serveur de support, explique ce dont ton serveur a besoin : un mini-jeu, un système d'économie, une commande propre à ta communauté, un lien avec un autre service…

  2. 2

    Le module est codé pour toi

    On valide ensemble ce qu'il doit faire, puis il est développé et testé. Il respecte les mêmes règles que le reste de Cyber : pas de permission inutile et pas de donnée gardée sans raison.

  3. 3

    Tu reçois ton identifiant

    Un code unique, réservé à ton serveur, du type CYB-7F3A-K9. Il ne fonctionne pas ailleurs.

  4. ✓

    Tu l'ajoutes en un clic

    Dans le tableau de bord, ouvre Modules puis « Ajouter un module avec un code », colle ton identifiant : Cyber installe le module tout seul, sans redémarrage ni nouveau bot à inviter.
