# Cyber · site vitrine

Site du bot Discord **Cyber**, hébergé avec GitHub Pages.

- `index.html` : la page
- `style.css` : le design
- `script.js` : menu mobile, recherche de commandes, animations
- `commandes.js` : liste des commandes (générée depuis le code du bot)
- `assets/` : logo, bannière, fond, aperçu du tableau de bord

Ce dépôt ne contient aucun secret : le token et le code du bot restent privés.
